## 1. 产品定位

**GEO 内容工作台**是面向品牌运营团队的生成式引擎优化（GEO）一站式工作台，解决「用户在 AI 搜索中问什么、品牌有没有被 AI 提及推荐、如何用内容提升 AI 可见度」。

核心价值链路：**AI 问答监测 → 可见度洞察 → 选题沉淀 → 内容生产 → 审核发布**。

- 单平台模式：全局唯一品牌档案（内置演示品牌「星野优选」，无品牌切换器）
- 双数据源：已接入腾讯 Answerbit GEO 平台时展示真实监测数据；未接入/调用失败自动回退本地演示数据（7 天爬升演示批次），体验无差异
- 离线模式（Mock）：后端不可达时自动切换纯前端演示数据，页面完整可逛

**全项目仅关注四个模型**：DeepSeek、豆包、千问、元宝（kimi 等其他引擎数据不进入产品）。

### 2.3 初始化序列

1. 页面加载 → `GET /api/platform`（成功后才渲染路由视图；各视图开头有兜底空态「平台信息未加载，请刷新页面重试」）
2. `/api/platform` 网络不可达且 mock 层可用 → 自动写入离线标记并重放请求
3. 视图运行时错误 → 显示「页面加载出错：…（多为浏览器缓存旧版页面，请 Cmd+Shift+R 强制刷新）」+ 错误 toast

### 2.4 全局交互组件

| 组件 | 规格 |
|---|---|
| **Toast** | fixed 右下角，多条垂直叠放；三类型：ok=绿（默认）/err=红/info=深灰；淡入后 3200ms 开始淡出、再 300ms 移除；无手动关闭、无堆叠上限 |
| **Modal** | 遮罩深灰半透明、弹窗靠上不垂直居中（py-10），遮罩自身滚动、**不锁 body 滚动**；关闭 = 点遮罩空白 / ✕ / 取消按钮（**Esc 不可关**）；同时只存在一个弹窗（覆盖式，无堆叠）；尺寸档位见各模块 |
| **确认弹窗** | 使用浏览器原生 `confirm()`，仅 2 处：删除监测问题（「删除该问题及其监测表现？」）、删除文章（「删除该内容？」）；驳回、知识卡删除标记等均**无确认** |
| **搜索框** | 全站 oninput 即时过滤（**无防抖**），重渲染后自动回焦点并把光标置到末尾，保证输入连续 |
| **日期显示** | 「MM-DD HH:mm」格式，不含年份 |

### 2.5 离线模式（Mock）

- 触发：后端网络不可达（fetch TypeError）时**自动进入**，toast「后端连接失败，已进入离线模式」；或手动设 `localStorage.wb_mock='1'`（**无可见 UI 开关**，退出需清 localStorage）
- 显隐：顶栏与侧栏的「● 离线模式」徽章仅在离线态显示
- 行为：全部 API 请求改走前端 mock 数据层（随机 180–430ms 延迟模拟网络），数据与后端 seed 演示数据同构；知识卡审核标记额外持久化到 `localStorage.wb_kb_reviews`

### 2.6 ⚠ 不复现清单（无界面入口的功能）

复现时**不需要**实现：回答对比弹窗（viewSamples）、监测中心跳回答记录（gotoMonAnswers）、问题转选题（topicFromQuery）、删除选题（delTopic）、删除监测问题（delMQ）、启停监测问题弹窗（toggleMQ）、Mock 开关 UI（toggleMock）、Answerbit 前端调试层（abFetch/abCall/abMode/abPool/abRetry）、添加选题弹窗（topicModal，已被添加问题弹窗取代）、采样进度弹窗元素（`#run-prog-*`，轮询为静默）、选题 LLM 拓词入口（接口保留，前端无按钮）。

## 4. 模块详述

### 4.1 监测中心（默认首页）

**数据加载序列**：并行拉 监测问题 + 批次列表 + 全局统计 + 知识卡 → 渲染运转条 → 对每个已完成批次并行拉样本（全部在前端聚合计算）。

**顶部运转条**：监测问题数 · 知识卡数 · 内容总数 · 待审核（amber）· 已发布（emerald）· 右侧固定「内容生产正常运转」+ 绿点。

**KPI 四卡**（口径说明即卡片副标题）：

| 卡片 | 指标名 | 口径 |
|---|---|---|
| 1 | AI提及率 | 无 error 样本中 `brand_mentioned` 占比，1 位小数 |
| 2 | 可见引用份额 | 全部引用域名计数中指向品牌官方域名的比例 |
| 3 | AI推荐率（首推率） | `brand_rank === 1` 的样本占比 |
| 4 | AI推荐率（前三位率） | `1 ≤ brand_rank ≤ 3` 的样本占比 |

上方一行说明：「基于 N 条采样回答 · M 个采样日」。无数据时分母按 1 处理（指标显示 0）。

**品牌趋势曲线**（卡片标题行右侧三枚指标切换 pill：AI提及率 / AI推荐率（前三位率）/ 平均排名）：
- 画布 720×250 SVG；中点二次贝塞尔平滑曲线（<3 点退化为折线）
- **颜色规则**：品牌固定 `#E6007E` 实线 2.5px；竞品取调色板（蓝/青/紫/黄…）循环、**虚线 5-4、opacity 0.8、1.8px**；数据点空心圆；图例区分实线/半透明线段
- 提及率模式额外画全部竞品曲线；前三位率/平均排名模式**仅品牌单线**；平均排名模式 **Y 轴反转**（越小越靠上），其余指标 Y 轴 0–100、5 条网格线
- X 轴：≤8 个点全显，否则按 `ceil(n/6)` 步进采样且强制含最后一点
- hover：每列透明热区 → fixed 跟随鼠标的 tooltip（右边界内钳制），显示日期 + 各系列色点/名称/值（null 显示 —）
- 曲线下方口径文案随指标切换（平均排名注明「越靠上越好」，提及率注明「虚线为竞品」）

**AI 提及率排行**（右栏条形图）：
- 竞品集合 = 品牌档案竞品（中英文逗号均可分割）∪ 样本中实际出现的竞品；按提及率降序排
- 每行：序号（前 3 名加粗）/ 名称 / 归一化条形 / 百分数（1 位小数）；本品牌行浅粉底高亮
- 顶部三格：「我的品牌 第 N 名」/「周期{当前指标名}」/「平均排名 `#x.xx`」

**最近内容**（仅统计接口 recent 非空时渲染）：标题 / 模板原文 / 状态徽章 / 生成时间；取 5 条；行点击开文章详情弹窗（同内容工厂）；「全部 →」跳内容工厂。

**筛选体系**（四弹层 + 指标切换，全局联动，筛选条上「重置」按钮仅当有非默认筛选时出现）：

| 弹窗 | 内容与交互 |
|---|---|
| 问题 | 「选择分析问题」：搜索框实时过滤（只重渲列表）+ 分组 chips（全部 + 数据中去重分组）+ 列表多选 +「全选本组」（范围=搜索+分组过滤后的可见集）；底部实时「已选 N 个」+ 清空/取消/应用；应用时 0 选 = 筛选清除；空态「没有匹配的问题」 |
| 时间 | 左侧快捷列（今天/昨天/近一周/近两周/近30天/近90天/全部）+ 右侧可视化日历（周一起始、前后月补灰、月份/年份下拉跳转、年份范围当前年±4）；两次点击成区间（再次点击闭合区间会重开；起点倒序点击自动交换；端点品牌色白字、中间浅粉）；「应用」仅在完整区间或「全部」时可用 |
| 模型 | 固定四模型，副文案「全项目仅关注以下四个模型」；每项显示当前时间范围内样本条数；「全选」按钮；应用时与四模型完全相同 = 筛选清除 |
| 标签 | 按维度分组展示标签值（来自监测问题的 tags），chips 多选、**跨维度取并集**；0 选 = 清除；无标签数据时「暂无标签数据」 |

**空态（两层）**：无批次 → 「暂无采样数据——先在选题库添加问题，再发起采样」+ 两个引导按钮；有批次但筛选后无样本 → 「当前筛选范围内没有采样数据，请调整问题 / 时间 / 模型筛选」。

### 4.2 选题库

监测问题与选题统一管理 + 内容生产发起点。

**数据组装**：并行拉监测问题 + 本地选题 → 批次列表取已完成批次**最近 2 期** → 分别拉两期分析（含全量问题指标）→ 逐问题拉该批次样本自算**前三提及率 t3**（带缓存防重复请求）。

**列表（8 列网格）**：勾选框 ｜ 问题（单行截断 + 标签 chips + 「已生成」徽章）｜ 排名 ｜ 提及率 ｜ 前三提及率 ｜ 回答记录 ｜ 启用状态开关 ｜ 内容生产（去生成/删除，右对齐）。

- **渲染条件**：问题不在最近监测期时，排名/提及率/前三/回答记录四列显示灰色 `—`，开关与生产按钮仍可用
- **「已生成」徽章**：该问题文本与本地选题 keyword 匹配且选题 status=used
- **趋势徽章**：排名徽章（变小=向好）与提及率徽章（变大=向好，单位 pt）；cur/prev 任一为 null 或**相等不显示**；`↑N` 绿 / `↓N` 红；title 显示「上期 x → 本期 y」
- **启用开关**：title「监测中，点击停用 / 已停用，点击开启监测」；点击后调 PATCH 接口 + toast + 整页刷新
- **回答记录**：跳转回答记录页并自动定位该问题的第一条对话（跳转标记一次性消费）
- **去生成**：跳内容工厂并打开生成向导（预填该问题）
- **删除**：原生 confirm「删除该问题及其监测表现？」→ 删除接口 → 重载（无成功 toast）

**筛选**：维度 pill（全部/决策机制/关注点/人群/品类/品牌/场景/约束）+ 搜索框 + 计数「N / M 个问题」；空态「没有符合条件的问题」。

**多选与批量**：勾选集合**跨筛选、跨搜索保留**（全局 Set）；表头全选框支持半选态（部分勾选时）；批量条在勾选非空时出现：「已选 N 个问题」+「全选当前范围（M）」（只加当前可见行）+「清空选择」+「▶ 发起采样」。

**发起采样弹窗**：
- 勾选为空时 toast「请先勾选要采样的问题」，不弹窗
- 模型列表固定四模型（默认全勾）；采样次数 1/2/3（默认 1，说明「每个问题每个模型提问几次，多次采样结果更稳定」）
- 任务数 = 勾选问题数 × 已选模型数 × 次数，实时联动
- 开始 → 创建批次 + toast「采样已启动：…= N 个任务」→ **静默轮询**（每 4s 查一次，无进度 UI），完成时 toast「采样完成：done/total 个任务」，当前在监测中心则自动刷新

**添加问题弹窗**：问题文本必填；分组输入框（datalist 常用分组：推荐/比较/替代/价格/风险/品牌验证/场景，可点选 chips）；**七维标签输入**（决策机制/关注点/人群/品类/品牌/场景/约束，各带 placeholder 示例，可留空，空值不提交）；默认分组「未分组」、market=cn。

### 4.3 大模型回答记录

左右分栏（等高 `calc(100vh - 250px)`、min 420px、各自独立滚动）。

**数据**：全部已完成批次样本拉平，按批次集合缓存（批次不变不重复拉取）；排序 = 先按问题文本、同问题内按引擎名。

**左列表项**：问题文本（2 行截断，选中态粉边+浅粉底）+ 日期 · 引擎色点 · 结果徽章（失败红/已提及绿/未提及灰）。顶部搜索框 + 筛选行。

**筛选**：时间（复用监测中心的日历弹窗）· 模型 chips（**从实际样本动态生成**，「全部模型」固定第一枚，其余带引擎色点）· 判定 chips（全部/已提及/未提及/失败——「失败」仅当存在失败样本时显示）· 搜索。

**右详情**：
1. 标题 + 元信息（时间 🕐 · 引擎色点+名 · 批次 #id）
2. 品牌信息条：平台名 + 结果徽章 +「位次 #N」（有位次时）+ 标签 chips
3. **对话式问答**：右侧品牌色气泡显示问题 → 下方引擎头像（首字母 + 引擎色）+ 引擎名 +「引用官网」徽章（own_domain_cited）→ 白底回答框，**品牌名及全部别名 `<mark>` 黄色高亮**；回答空显示「（空）」
4. 引用域名 chips（与品牌官方域全等 → 品牌色底加粗）+「提及竞品：」列表

**交互规则**：筛选变化后若当前选中项被过滤掉 → **自动回落到第一条**；跳转定位标记一次性消费；左列表无匹配 →「无匹配对话」；未选中 →「左侧选择一条对话查看内容详情」。

### 4.4 知识库

**结构**：单一知识卡治理视图（⚠ 无独立「文档管理」tab——文档入库通过右上「+ 添加文章」弹窗完成）。

**顶部 8 格 KPI**：卡片（当前/全部）、免审（绿「官方·无冲突」）、抽检（amber「含外部口径」）、必审（红「有事实冲突」）、待人工审核（红）、带使用提醒（amber）、含非官方口径冲突、已审核（粉）。

**知识卡列表（卡片式）**：标题 + card_id（mono 灰）+ chips 行（质量三档 / 审核标记 / 主题粉 / 分类绿 / 来源主体灰 / 来源类型：官方蓝·转载amber·其他灰 / time 缺失显示红「time 待补」/「说法不一致」红 /「合并 N 张」紫 /「待人工审核」红）+ 正文前 160 字 2 行截断；已删除卡整卡半透明。

**筛选**：搜索框（搜标题/正文/引文）+ 质量/主题/来源类型三个动态下拉（选项从数据聚合）+ 标记下拉（已通过/已拒绝/已删除/未标记）+「只看需注意」勾选 + 计数「显示 X / Y 张（全部 Z 张）」；分页为**本地「继续显示」按钮**（每页 30 张，按钮「继续显示（还有 N 张）」）；空态「没有符合条件的卡片」。

**审核操作**（卡片右侧）：「✓ 通过」「✕ 拒绝」「删除」三按钮（当前已应用者实色高亮）+ 有审核时出现「撤销」+「详情 →」；点击即时提交（无 toast、无确认）；删除 = 打标记而非物理删除。

**知识卡详情弹窗（max-w-3xl）**：标题 + card_id + 版本号；全文；⚠ 使用提醒折叠块（默认展开，amber）；「待确认差异」冲突块（红，对方卡对照）；来源引用列表（来源类型/文档名/pid +「引文已核对」绿或「引文待核对」红 + 原文链接）；底部审核区：三标记按钮 + 撤销 + **备注 textarea（可选）+ 保存备注**（无标记保存时默认按「通过」记）。撤销时关弹窗，设标记后重开详情。

**添加文章弹窗（双 tab）**：
- Tab1 粘贴文章：标题 + 正文（placeholder 注明「Markdown 优先，会按标题结构自动分块进入证据池」）；校验两者非空；成功 toast「文章已入库，切分为 N 个知识分块」
- Tab2 网页链接：URL 必填 + 标题（留空自动取网页标题）；说明「点击导入后会抓取网页，自动剥离导航/脚本等噪音并提取正文」；过程 toast「正在抓取并解析网页…」；成功 toast「《标题》已导入，正文 N 字 · N 个分块」

### 4.5 内容工厂

**文章列表**：筛选 tabs（全部内容/待审核/已通过/已驳回，各带计数）+ 标题搜索；表列：编号 #id / 标题（截断）/ 来源徽章（本地上传-蓝⬆ / AI 生成-粉✦）/ 目标模型（模型图标，空显示 —）/ 模板原文 / 状态徽章（待审核-amber、已通过-蓝、已发布-绿、已驳回-红、草稿-灰）/ 生成时间；整行点击开详情。

空态两层：无任何文章 → 大空态卡「还没有产出内容」+「＋ 生产内容」按钮；筛选无结果 → 表格行「没有符合条件的内容」。

**生产方式选择弹窗（max-w-xl）**：两卡「AI 生成」（粉底、「推荐」角标）/「本地上传」；说明「两种方式产出的内容统一进入审核流程」。

**AI 生成向导（两步）**：

第 1 步：目标模型 chips（四模型带图标，多选，选中附 ✓）+ 优化的问题多选（仅**启用中**的问题；搜索框 + 计数「已选 N/20」+「全选当前范围」（受上限截断）+ 列表行：问题 + 分组灰标 + 提及率徽章：**<40% amber / ≥40% emerald / null 灰字「暂无提及率」**）；上限 20，超出 toast；「下一步」需 模型≥1 且问题≥1。选题库带入时顶部固定粉底「选题带入」预选项。

第 2 步：摘要行「将生成 N 篇 · 模型图标 · 修改（跳回）」；模式二选一：
- **模板化生产**：5 种模板卡片，名称+结构说明——对比选购（核心结论前置/选购标准/逐项对比表/推荐/FAQ）、案例实证（背景问题/方案/量化结果（须有证据）/复盘）、风险避坑（风险清单/判断标准/正确做法/一句话结论）、FAQ问答（是什么/怎么选/多少钱/注意什么，结论先行）、场景方案（场景/痛点拆解/分步方案/能力清单/效果预期）；选中卡粉边+浅粉底+右上「✓ 已选」
- **仿写高引用范文**：三来源——① 知识库文档列表（默认 6 条，「展开更多（N）」，行含来源类型标签与字数）；② 手动指定链接（解析按钮 → 预览卡标题+前 160 字 →「采用该范文」；空链接/解析中状态处理）；③ 手动指定内容（标题可选留空自动命名「（手动指定范文）」，正文 **≥50 字**校验）。选定后顶部出现「仿写对象」条可取消
- 「✦ 开始生成（N 篇）」按钮：仿写模式必须已选范文才可用；知识库无文档时显示「知识库暂无文档，可在下方手动指定范文」

**生成进度弹窗（max-w-xl）**：串行逐篇执行（先确保问题有本地选题，无则自动创建），状态流转 wait→run→ok/err；弹窗含标题（正在生成内容…/生成完成）+ 模式与模板/范文摘要 + 品牌色进度条 + 任务列表（spinner 生成中/✓ 已生成/✕ 失败（title 悬浮显示错误）/空心圆 等待中）；全部完成后：有失败显示红「N 篇生成失败，可重新发起生成」，否则「全部生成成功，已进入待审核」+ 完成按钮；结束自动刷新列表。

**本地上传弹窗**：标题 **≥2 字**、正文 **≥50 字** 校验；提交按钮 disable + 文案变「上传中…」；成功 toast「上传成功，已进入待审核」。

**文章详情弹窗（max-w-5xl，左右 2:1 分栏，各自滚动）**：
- 头部（sticky）：标题 / 状态徽章 / 模板 / 分数（≥80 绿、否则 amber）/ AI 审稿判定（✅ 直接发 / ✏️ 局部改 / 👤 要人看 / — 未启用）
- 左栏：Markdown 渲染正文
- 右栏：① 规则核查（每条红色「type：detail」，无问题绿字「规则全部通过」）；② AI 审稿（comment + issues 列表，无则「（未启用或未审稿）」）；③ 证据（知识库，只展示前 800 字）
- **操作按钮可见条件**：「✓ 通过审核」「✕ 驳回」**仅待审核状态**；已发布显示「渠道：{渠道} · 链接」；「↻ 重新审稿」「✎ 编辑内容」任何状态可见；「删除该内容」红色文字链接样式任何状态可见

**操作行为**：通过/驳回 → toast「已通过/已驳回」→ 重开详情 + 在工厂页则刷新列表；重新审稿 → 先 toast「审稿中…」完成后「审稿完成」；编辑（max-w-3xl 弹窗：标题 + 16 行正文 textarea）→ toast「已保存」；删除 → confirm → 关弹窗刷新（无成功 toast）。

## 5. 关键口径与业务规则

| 口径 | 规则 |
|---|---|
| 关注模型 | DeepSeek、豆包、千问、元宝；回答记录模型 chips 从样本动态生成；kimi 不进入产品 |
| 提及判定 | 回答中出现品牌名或任一别名即「已提及」；别名命中处向前 20 字符内出现否定词（不是/并非/不包括/排除/谈不上/不算）→ 该次命中不算提及；全部命中均被否定 → 位次为空且标记待复核 |
| 排名 | 品牌首次有效提及位置 vs 各竞品首次出现位置合并排序，品牌位次 = 序号+1 |
| 负面线索 | 首次提及前 80 / 后 160 字符窗口内出现 13 个负面词（不推荐/避雷/骗局/智商税/慎入/差评/翻车/割韭菜/投诉无门/跑路/虚假宣传/夸大宣传/退款难）→ 待复核 |
| 点名问题 | 提问点名品牌（brand_in_question）只计入品牌认知，**不参与**提及率/排名/引用/竞品等可见性聚合 |
| 选题库指标 | 提及率/排名来自平台单日**全量问题**真实指标（非抽样）；前三提及率由该问题批次样本自算 |
| 状态机 | 草稿→待审核→已通过→已发布；驳回可经复审回到待审核；**仅「已通过」可发布**（唯一强制约束） |
| 选题联动 | 生成成功后选题置「used」（同一选题可重复生成） |
| 批次 | AB 模式按自然日（yyyymmdd）组织，上限 15 个批次；本地模式 = 问题×引擎×次数后台线程执行，每条样本实时提交 |
| 采样轮询 | 每 4s 静默查询，完成即停并 toast |

## 7. 典型使用路径

1. **接入**：管理员配置 Answerbit Key 与 LLM 供应商（见技术方案 §8），全站切真实数据
2. **监测**：监测中心看 KPI 与竞品趋势 → 按问题/时间/模型/标签下钻 → 回答记录看原文与引用
3. **生产**：选题库筛低提及率问题 → 勾选「去生成」→ 向导选模型 + 模板/范文 → 生成 → 审核 → 发布
4. **沉淀**：知识卡审核 → 知识库文档入库 → 反哺生成证据
