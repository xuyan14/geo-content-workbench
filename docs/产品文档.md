# GEO 内容工作台 · 产品需求文档

> 适用对象：产品、运营、研发
> 配套文档：`docs/技术方案.md`（架构、接口、算法实现细节）

---

## 1. 产品概述

### 1.1 定位

面向品牌运营团队的 GEO（生成式引擎优化）一站式工作台，回答三个问题：

1. **用户在 AI 搜索中问什么**——监测问题库持续沉淀真实提问
2. **品牌有没有被 AI 提及推荐**——量化可见度并对比竞品
3. **如何提升 AI 可见度**——基于监测数据与知识库，生产并发布 GEO 友好内容

核心链路：**AI 问答监测 → 可见度洞察 → 选题沉淀 → 内容生产 → 审核发布**。

### 1.2 目标用户

品牌市场 / GEO 团队、内容运营、平台内部运营。

### 1.3 数据形态

- **已接入监测平台**（腾讯 Answerbit GEO）：全站展示真实监测数据
- **未接入**：自动使用内置演示数据（含 7 天爬升的演示批次），产品体验完全一致
- **离线模式**：后端不可达时自动切换纯前端演示数据，页面功能完整可体验
- 内置数据说明：监测问题集与词包标签为**真实 GEO 词包数据**（120 条问题 × 7 维标签）；品牌档案与知识卡为虚构演示数据，可替换

### 1.4 范围约定

- 单平台模式：全局唯一品牌档案，不做品牌切换
- **全项目仅关注四个模型**：DeepSeek、豆包、千问、元宝；其他引擎数据不进入产品

## 2. 信息架构

左侧固定导航五项，默认进入监测中心：

| 模块 | 定位 | 核心出口 |
|---|---|---|
| 监测中心 | GEO 可见度总览 | 下钻问题明细、跳转回答记录 |
| 选题库 | 监测问题统一管理 | 发起采样、跳转内容生产 |
| 大模型回答记录 | 采样原始回答沉淀 | 查看回答原文与引用 |
| 知识库 | 可信信息沉淀 | 为内容生产提供证据 |
| 内容工厂 | 内容全生命周期 | 生成 → 审核 → 发布 |

页面间通过场景化跳转联动（例：选题库低提及率问题 → 一键带入生成向导；选题库/监测中心 → 回答记录自动定位到对应问题）。

## 3. 功能需求

### 3.1 监测中心

**顶部运转条**：常驻展示监测问题数、知识卡数、内容总数、待审核、已发布与系统运转状态，让运营一眼确认体系在正常运转。

**KPI 两组七卡**（分「被看见」与「被信任」两组，每卡副标题即口径说明）：

**被看见**——品牌在 AI 回答中被提及与推荐的程度：

| 指标 | 含义 |
|---|---|
| 提及率 | 品牌在目标问题回答中被提及的样本占比 |
| Top1 率 | 品牌被 AI 列为第 1 推荐的样本占比 |
| Top3 率 | 品牌位列前 3 位次推荐的样本占比 |
| 平均提及排名 | 品牌首次被提及的平均位次（越小越好） |

**被信任**——品牌作为可信信源被 AI 引用的程度：

| 指标 | 含义 |
|---|---|
| 品牌内容引用次数 | 品牌自有投放内容的引用总次数 |
| 品牌内容引用率 | 品牌内容引用占全部引用的比例 |
| 官网引用率 | 品牌官网引用占全部引用的比例 |

**品牌趋势曲线**：
- 四指标切换（与「被看见」指标卡对齐）：提及率 / Top1 率 / Top3 率 / 平均提及排名
- 提及率模式下同时展示品牌曲线与竞品曲线（虚线区分）；竞品集合取自品牌档案配置的竞品名单；其余指标仅品牌单线
- **图例可点击**：点击图例中的品牌可隐藏 / 恢复该品牌曲线，用于聚焦对比
- 平均提及排名指标「数值越小越好」，纵轴按此呈现
- 悬停查看任意日期各品牌的数值（仅显示当前可见品牌）

**AI 提及率排行**：品牌与竞品同榜排名，自家品牌高亮并标注名次；支持按当前时间范围查看周期指标与平均排名。

**最近内容**：展示最新产出的 5 篇内容（标题/模板/状态/时间），点击进入详情；提供「全部」入口直达内容工厂。

**筛选体系**（四维 + 指标切换，全局联动）：
- **问题**：按分组 + 关键字搜索 + 多选/全选本组
- **时间**：预设档（今天/昨天/近一周/近两周/近 30 天/近 90 天/全部）+ 日历自定义区间
- **模型**：仅四大模型，显示各模型样本量
- **标签**：按业务标签维度分组多选（见 §5 标签体系）
- 筛选偏离默认时出现「重置」按钮

**状态与空态**：无采样数据时引导去选题库添加问题并发起采样；筛选无结果时提示调整筛选条件。

### 3.2 选题库

监测问题与选题的统一管理入口，也是**内容生产的发起点**。

**问题列表**，每行展示：
- 问题文本（超长截断展示，悬停查看完整问题）+ 业务标签 + 「已生成」徽章（已产出过内容的问题）
- 三个监测指标：排名、提及率、前三提及率，均带与上期对比的趋势标识（升绿/降红，无对比数据或持平不显示）
- 操作：回答记录（跳转并定位）、监测启停开关、去生成、删除（需确认）
- 问题不在最近监测期时，指标列显示占位符，开关与操作仍可用

**筛选与查找**：业务标签维度快捷筛选（全部/决策机制/关注点/人群/品类/品牌/场景/约束）+ 关键字搜索；显示当前筛选计数。

**多选与批量**：
- 支持跨筛选、跨搜索保留勾选状态；表头支持全选与半选态
- 批量操作条：「发起采样」——选择模型（四模型，默认全选）与采样次数（1–3），实时展示预计任务量；发起后后台执行，完成时提示采样结果

**问题管理**：添加问题（支持录入分组与七个业务标签维度）；删除问题需二次确认。

**生产联动**：「去生成」携带问题直达内容工厂生成向导，并自动预选该问题。

**指标口径**：提及率与排名来自平台当日全量问题指标（非抽样估算）；前三提及率由该问题批次样本计算。

### 3.3 大模型回答记录

每次采样的原始回答沉淀，左右分栏：左为对话列表，右为回答详情。

**筛选**：时间（与监测中心共用日历组件）、模型（按实际样本动态生成）、判定结果（全部/已提及/未提及/失败）、关键字搜索。

**对话列表**：每项展示问题摘要、日期、模型标识、判定徽章；当前选中项高亮。

**回答详情**：
- 对话式呈现：品牌色问题气泡 → 模型回答全文（Markdown 文档化渲染）
- **品牌高亮**：回答正文中品牌名及全部别名高亮标注
- 元信息：判定徽章、位次、业务标签、批次号
- **引用来源**：表格化呈现（序号 / 来源页面标题 / 所属站点），点击标题或站点可跳转引用原文；引用品牌官方域名的行高亮并标注「品牌官网」
- 提及竞品列表

**交互约定**：筛选变化后若当前选中项被过滤，自动定位到第一条；从其他页面跳入时自动定位到目标问题的第一条对话（该问题暂无采样记录时，搜索框预填该问题并提示「暂无采样回答记录」）。

### 3.4 知识库

**知识卡治理**（知识可信度管理）：
- **概览**：卡片总数与质量分布（免审/抽检/必审/待人工审核等）
- **卡片列表**：标题、标识、质量与来源标签、正文摘要；已删除卡片弱化展示
- **筛选**：关键字搜索 + 质量/主题/来源类型/审核标记筛选 + 「只看需注意」；分页加载
- **人工审核**：通过/拒绝/删除三种标记，操作即时生效（无需确认）；有审核记录时可撤销，可附审核备注
- **卡片详情**：全文、使用提醒（默认展开）、冲突对照（与其他卡片的说法差异）、来源引用与引文核对状态

**知识库文档入库**（三种方式）：
- **粘贴文章**：标题 + 正文，按结构自动分块进入证据池（Markdown 优先）
- **网页链接**：自动抓取并剥离页面噪音、提取正文入库
- **知识卡导入**：批量将审核通过的知识卡导入知识库（幂等，重复导入不产生重复文档）

### 3.5 内容工厂

内容全生命周期：生产 → 待审核 → 通过/驳回 → 发布。

**内容列表**：状态筛选（全部/待审核/已通过/已驳回）+ 标题搜索；每行展示来源标识（AI 生成/本地上传）、目标模型、模板、状态、时间；点击进入详情。

**生产方式二选一**（产出统一进入审核流程）：
- **AI 生成向导**（两步）：
  - 第一步选目标模型（多选）与优化的问题——问题列表仅展示监测中的问题，每条带提及率标识（低于 40% 黄色提醒、达标绿色），支持搜索与全选，上限 20 个
  - 第二步选生产模式：
    - **模板化生产**：五种文体模板（对比选购/案例实证/风险避坑/FAQ 问答/场景方案），每种标注章节结构
    - **仿写高引用范文**：范文可来自知识库文档、在线链接解析或手动粘贴；系统提炼范文结构按其骨架生成，不复述范文内容
  - 生成过程逐篇展示进度（等待/生成中/已生成/失败），全部完成后内容进入待审核
- **本地上传**：标题 + 正文直接入库，进入同一审核流

**审核与发布**：
- 每篇内容经过双重把关：**规则核查**（绝对化用语、无来源数据、篇幅、结构）+ **AI 审稿**（结论三档：可直接发布 / 建议修改 / 需人工确认，附评分与意见）
- 人工操作：通过、驳回、重新审稿、编辑、发布、删除（删除需确认）
- 仅「已通过」的内容可发布；发布成功后记录渠道与链接
- 详情页展示：正文、审稿意见与评分、规则核查结果、引用的证据来源

## 4. 全局交互约定

| 约定 | 要求 |
|---|---|
| 提示反馈 | 操作结果以轻量 toast 告知（成功/失败/进行中）；右下角出现，自动消失 |
| 弹窗 | 覆盖式弹窗，点击遮罩空白或取消按钮关闭；同一时间仅一个弹窗 |
| 危险操作 | 删除监测问题、删除内容需二次确认；驳回等其余操作不设确认 |
| 搜索 | 输入即时过滤，无需提交；过滤后保持输入焦点 |
| 空态 | 每个列表/视图需有明确空态文案与下一步引导（见 §7） |
| 日期显示 | 统一「月-日 时:分」格式 |
| 数字展示 | 指标保留 1 位小数，趋势对比取整 |

## 5. 业务规则与口径

| 规则 | 说明 |
|---|---|
| 提及判定 | 回答中出现品牌名或任一别名即视为提及；否定语境（如「不是/并非」）中的出现不算提及 |
| 排名 | 品牌首次有效提及在回答中的位次（与各竞品首现位置合并排序） |
| 负面识别 | 品牌首次提及附近的负面表述会标记「待复核」 |
| 点名问题 | 提问直接点名品牌的问题只计入品牌认知，**不参与**可见性指标（避免虚高） |
| 选题联动 | 问题产出内容后标记「已生成」；同一问题可多次生成 |
| 内容状态机 | 草稿 → 待审核 → 已通过 → 已发布；驳回后可重新审稿回到待审核；**仅已通过可发布** |
| 标签体系 | 七个业务维度：人群/品类/品牌/场景/约束/决策机制/关注点；来自品牌 GEO 词包，与平台侧分类无关；未命中词包的问题标签留空 |
| 批次 | 一次采样 = 勾选问题 × 所选模型 × 次数；接入监测平台后按自然日组织批次 |

## 6. 视觉风格

- **主色**：品牌粉（#E6007E），用于主按钮、选中态与高亮；整体中性灰底、内容白色卡片
- **层级**：顶栏 + 左侧导航 + 内容区三段式；导航选中态带品牌色竖条
- **克制**：卡片无重投影、按钮轻量化（列表内操作为文字级按钮）、徽章统一小圆角
- **表格**：浅底表头、行悬停反馈；文字单行截断，为标签留出空间
- 详细规格（间距/字号/组件尺寸）以实现为准，见技术方案

## 7. 空态与引导文案

| 位置 | 文案要点 |
|---|---|
| 监测中心（无数据） | 暂无采样数据——引导去选题库添加问题并发起采样 |
| 监测中心（筛选无结果） | 提示调整问题/时间/模型筛选 |
| 选题库 | 没有符合条件的问题 |
| 知识库 | 没有符合条件的卡片 |
| 内容工厂（无内容） | 引导选择 AI 生成或本地上传开始第一篇 |
| 回答记录（无数据） | 引导去选题库发起采样 |
| 回答记录（无选中） | 左侧选择一条对话查看内容详情 |
| 生成向导（无范文） | 知识库暂无文档，可手动指定范文 |

## 8. 典型使用路径

1. **接入**：配置监测平台 API Key 与 AI 模型，全站切换真实数据
2. **监测**：监测中心看 KPI 与竞品趋势 → 按问题/时间/模型/标签下钻 → 回答记录看原文与引用
3. **生产**：选题库筛低提及率问题 → 去生成 → 向导选模型与模板/范文 → 生成
4. **审核发布**：内容工厂审核（AI 审稿 + 人工）→ 通过 → 发布
5. **沉淀**：知识卡审核入库 → 知识库文档维护 → 反哺生成证据质量
